Each numbered patch series was applied to its exact base using a temporary Git index. The resulting tree hash matches the signed contribution exactly. Apply in numerical order with git am in clean component checkouts; do not layer over the older experimental series. Alternatively use the signed fork commit directly, not both. Buildroot packaging does not automatically apply these patches; select the patched component sources before rebuilding. Preserve the board/generic NOR config fragments and the experimental peripherals fragment, and apply the generic NOR DT overlay for CramFS. Keep the known-good rollback images and verify slot sizes.

## Validated changes

- SPL: analog I2C clock gating retains correct MODEM_LPCON bit 2; initial MPLL 400 MHz/MSPI 200 MHz with bounded calibration and adjusted PSRAM timing. Ten repeated hardware boots and the earlier 4 MiB pattern test (180 rounds) passed; steady-state PSRAM physical timing is not independently measured.
- Linux: RMT TX v1.2 and WS2812 multicolor LED consumer, TX0 verified, final interrupt/teardown hardening; TX1–TX3 concurrency and physical waveform measurements pending. Ethernet, PTP clock registration and virtual CAN interface available; physical CAN FD and USB peripheral tests pending.
- OpenSBI: ROM system reset replaces single-core reset. 18 confirmed software resets (3 exploratory, 15 final), including explicit cold/warm Linux modes. Six network checks negotiated Gigabit full duplex and obtained DHCP; preliminary Internet probes 11/12, final gateway and Internet probes 40/40, no RX/TX errors. RMT fade resumed. No true power-cycle or shutdown validation.
